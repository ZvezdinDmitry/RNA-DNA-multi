# ОБРАБОТКА МНОЖЕСТВЕННО КАРТИРОВАННЫХ ПРОЧТЕНИЙ В ДАННЫХ РНК-ДНК ВЗАИМОДЕЙСТВИЙ
Репозиторий проекта по разработке EM-алгоритма для разрешения множественно картированных чтений в полногеномных данных РНК-ДНК взаимодействий.

- `multimapping` - код EM-алгоритма, препроцессинга, симуляции данных и визуализации.
- `scripts` - .py срипты для запуска из командной строки.
